# 콘티 포맷 카탈로그

캔버스는 4:5 세로(1080x1350)만 지원한다. 첫 장은 표지(cover), 마지막 장은 엔딩(ending)이다. episode.json 의 format 에 아래 id 를 적는다. `toon formats` 가 같은 목록을 보여 준다.

근거 표기: **확인** = 실제 게시물 슬라이드나 공식·1차 자료로 본 것, **사례** = 계정·제목은 확인했지만 장 구성은 추정, **이론** = 만화·마케팅 가이드에서 옮긴 것. 출처는 맨 아래.

## 고르는 법

| 목적 | 먼저 볼 포맷 |
| --- | --- |
| 공감·웃음으로 퍼뜨리기 | anecdote, kishotenketsu, punchline, comparison, expectation |
| 저장(다시 보기) 늘리기 | ranking, explainer, checklist, beforeafter |
| 팔로우·정주행 만들기 | serial, episodic |
| 댓글·참여 | typecompare, reader, quiz |
| 협찬·공구 | sponsored, groupbuy |

## 모든 포맷에 공통인 규칙

- 한 편에 메시지 하나. 표지는 비팔로워가 넘길 이유가 되게 쓴다(인스타툰 독자의 다수는 팔로우가 아니라 둘러보기·추천으로 본다).
- 2장도 표지만큼 강하게. 넘기지 않은 사람에게 2장부터 다시 보일 수 있다(보도 인용).
- 엔딩의 행동 요청은 하나만(팔로우, 저장, 댓글, 다음 화 중 하나).
- 정보형은 끝에서 두 번째 장에 요약 한 장. 이야기형은 요약 대신 여운이나 다음 화 예고.
- 장 수 기본 6~10장. 이야기 연재(serial)는 실제 계정에서 10~17장도 흔하다(확인). 인스타그램 캐러셀 상한은 20장.

## 장 레이아웃 요령 (확인: 사연툰·직장툰 실제 슬라이드)

- 한 장에 컷 2~4개를 세로로 쌓는 구성이 많다. 장면 문구에 "two stacked panels" 처럼 컷 수를 적는다.
- 컷 아래 흰 띠에 1인칭 내레이션("나는 대기업에 다니고…")을 두는 방식이 사연툰의 표준이다. narration 상자를 컷 아래 여백에 둔다.
- 메신저 화면 컷은 그림에서 빈 화면 휴대폰만 그리고 대화는 식자로 얹는다.
- 연재물 표지에는 화 번호·부제 칩("(1) 절친과 남편의 첫상담"), 사연물은 "실제 사연을 각색했습니다" 고지를 작게 둔다.

## 1. ranking — 랭킹형 (TOP N)

항목을 순서대로 보여 주고 마지막에 반전이나 공감 한마디. 저장·공유형. (현재 예제 2편이 이 포맷)

| 장 | kind | 역할 | 대사 |
| --- | --- | --- | --- |
| 1 | cover | 제목 3줄(가운데 강조) + 주인공 상반신 | 0 |
| 2 | body | 왜 이 순위를 매기게 됐는지 | 1~2 |
| 3 | body | 3위 (narration "3위. …") | 2~3 |
| 4 | body | 2위, 3위보다 강한 반응 | 2~3 |
| 5 | body | 1위 공개 직전 뜸 들이기, 효과음 하나 | 1~2 |
| 6 | body | 1위, 가장 큰 컷 | 2~3 |
| 7 | body | 반전 또는 저장하고 싶은 팁 한 줄 | 2 |
| 8 | ending | 마무리 컷 + 시리즈 엔딩 | 0~1 |

표지 예: "AI가 제일 그럴듯하게 틀리는 순간 TOP 3", "월급날 장바구니에 제일 먼저 담는 것 TOP 3"

## 2. anecdote — 일화형 (썰 한 편)

내가 겪은 작은 사건 하나를 한 편으로 끝내고 웃음이나 공감 한 줄로 닫는다. 일상툰의 기본형. (사례: 인봉툰)

| 장 | 역할 |
| --- | --- |
| 1 | 표지: 결과를 암시하는 제목 |
| 2 | 상황 설정 |
| 3~4 | 사건 전개 |
| 5 | 당황·반전 |
| 6 | 깨달음이나 웃음 한 줄 |
| 7 | 엔딩 |

표지 예: "지하철에서 내릴 역을 지나친 날", "퇴근길 빵 한 봉지"

## 3. kishotenketsu — 기승전결 확장형

4컷 기승전결을 컷당 1~2장으로 늘린다. "전"에서 예상을 비튼다. (이론)

| 장 | 역할 |
| --- | --- |
| 1 | 표지 |
| 2 | 기: 상황 한눈에 |
| 3~4 | 승: 기대를 키움 |
| 5~6 | 전: 예측을 흔듦 |
| 7 | 결: 펀치라인 또는 여운 |
| 8 | 엔딩 |

점검: "전" 장을 가려도 이야기가 이어지면 "전"을 다시 쓴다.

## 4. punchline — 셋업-펀치라인형 (반복의 깨짐)

같은 구도를 세 번 반복해 리듬을 만들고 네 번째에 깬다. 해설 대사로 반전을 설명하지 않는다. (이론)

| 장 | 역할 |
| --- | --- |
| 1 | 표지: 반복될 행동 암시 |
| 2~4 | 같은 구도 3회 반복 (장면 문구에 "same composition as page 2") |
| 5 | 깨짐 |
| 6 | 정적 컷이나 여운 |
| 7 | 엔딩 |

표지 예: "알람 세 번 끄고 일어났더니", "오늘도 '내일부터'라고 했다"

## 5. comparison — 상황극 비교형 (이럴 때 vs 저럴 때)

한 인물이 상황·상대에 따라 달라지는 모습을 쌍으로. 한 장을 위아래로 나눠 한 쌍을 넣어도 된다. (사례: 불개미상회, 밥풀이툰)

| 장 | 역할 |
| --- | --- |
| 1 | 표지: "A vs B" |
| 2~5 | 쌍 1~4 (장마다 위 A / 아래 B) |
| 6 | 가장 극단적인 쌍 |
| 7 | 한 줄 결론 + 엔딩 |

표지 예: "회식 갈 때 vs 퇴근할 때", "월요일의 나 vs 금요일의 나"

## 6. expectation — 기대 vs 현실

기대 컷과 현실 컷을 한 쌍씩. 취직·육아·다이어트·자취에 강하다. (사례: 밥풀이툰 "취직 전 취직 후", 인봉툰 "육아의 이상과 현실")

| 장 | 역할 |
| --- | --- |
| 1 | 표지: "○○ 기대 vs 현실" |
| 2~6 | 장마다 위 기대 / 아래 현실 (기대 쪽은 밝고 반짝이게, 현실 쪽은 어둡고 지친 표정) |
| 7 | 가장 큰 간극 또는 위로 한 줄 |
| 8 | 엔딩 |

## 7. explainer — 문제→원인→해결 (정보툰)

고민을 짚고, 원인을 설명하고, 해결을 단계로. 캐릭터 문답으로 푼다. 끝에서 두 번째 장에 요약. (사례: BLSN 변리사툰, 서울노동권익센터 정보툰)

| 장 | 역할 |
| --- | --- |
| 1 | 표지: 질문형 제목 |
| 2 | 공감 "나 얘기네" (흔한 오해·실수 장면) |
| 3 | 원인 |
| 4~6 | 해결 1·2·3 (장당 하나) |
| 7 | 요약 한 장 (저장용, narration 상자 여러 개) |
| 8 | 엔딩 (행동 하나) |

화면·화이트보드 글자는 in_image_text 에 10자 안팎으로만. 사실·수치는 콘티 단계에서 출처를 확인한다.

## 8. checklist — 체크리스트·리스트형 (N가지)

번호 항목을 장마다 하나씩, 마지막에 한 장 요약. "~한 사람 특징" 같은 공감 목록도 같은 틀. (이론)

| 장 | 역할 |
| --- | --- |
| 1 | 표지: "N가지" |
| 2 | 왜 필요한가 |
| 3~7 | 항목 1~5 (narration "1/5 …") |
| 8 | 요약 + 엔딩 |

랭킹형과 달리 순위·뜸 들이기가 없고 항목이 대등하다.

## 9. beforeafter — 비포/애프터

전후를 먼저 대비하고 바뀐 과정을 푼다. 정리·습관·인테리어·공부법. (이론)

| 장 | 역할 |
| --- | --- |
| 1 | 표지: 전→후 한 장 대비 |
| 2 | 전의 고민 |
| 3~5 | 바뀐 과정 |
| 6 | 후 결과 |
| 7 | 요약 |
| 8 | 엔딩 (저장 유도) |

## 10. typecompare — 유형 비교형 (MBTI, T vs F)

같은 상황에서 유형별 반응. 독자가 자기 칸을 찾아 댓글을 단다. (사례: @mbti_toon, 홍리 〈직장인 T와 F〉)

| 장 | 역할 |
| --- | --- |
| 1 | 표지: 상황 + 유형 수 |
| 2 | 상황 제시 |
| 3~6 | 유형별 반응 (장당 2~4유형, 한 장을 2~4칸으로 나눔) |
| 7 | 가장 극단적인 유형 |
| 8 | "너는 무슨 유형?" 댓글 유도 엔딩 |

유형별 고정관념을 비하로 쓰지 않는다. 결론은 "정답은 없다" 쪽이 무난하다.

## 11. serial — 사연·제보 연재형 (n화, 다음 화에 계속)

독자 제보를 각색해 3~5화로 나누고 매 화 끝에서 끊는다. **확인**: 그리고툰 「남이 버린 쓰레기로 신혼집 채운 남편 1」 10장, 쏘피 「절친의 연애상담 메이트가 내남편? (1)」 17장.

| 장 | 역할 |
| --- | --- |
| 1 | 표지: 제목 + 화 번호·부제 칩 + "실제 사연을 각색" 고지 |
| 2~3 | 인물·관계 소개 (컷 아래 1인칭 내레이션) |
| 4~(n-2) | 갈등 확대 (장마다 컷 2개, 내레이션 띠) |
| n-1 | 가장 센 장면 |
| n | 끊기: "- 계속 -" 또는 다음 화 미리보기 |

- 장 수 10~17장도 정상이다(상한 20).
- 엔딩은 팔로우 대신 "계속"(ending 공식이 아니라 그 화의 마지막 body 처럼 쓰고, series.ending 은 마지막 화에만).
- 실존 인물이 특정되지 않게 이름·직장·외모·지역을 바꾼다. 제보자 동의 없는 사연은 쓰지 않는다.
- 마지막 화는 "○화 완결"로 표기하고 속 시원한 결말.

## 12. episodic — 세계관 에피소드형 (ep.N)

고정 캐릭터와 관계로 매 화 독립 에피소드, 번호를 붙여 정주행하게 한다. serial 과 달리 한 화 안에서 끝나지만 다음 화로 이어지는 떡밥을 하나 남긴다. **확인**: 하루살이 「#하루살이회사툰 4 | ep.60」 8장, 장마다 컷 3~4개, 노란 내레이션 상자, 마지막 컷 "계속 ▶".

| 장 | 역할 |
| --- | --- |
| 1 | 표지: 시리즈명 + ep 번호 + 첫 장면 |
| 2~(n-1) | 상황 → 사건 → 반전 (장당 컷 3~4개) |
| n | 캐릭터 마무리 컷 + 다음 화 한 줄 |

## 13. reader — 독자 참여형 (댓글·사연 그려주기, 무물)

독자가 보낸 요청이나 질문을 골라 그려 답한다. 5장 안팎의 짧은 편. (사례: 키크니 〈무엇이든 그려드립니닷!〉)

| 장 | 역할 |
| --- | --- |
| 1 | 표지: 요청 댓글 인용 (narration 상자로 댓글 모양) |
| 2~3 | 사연 요약과 상황 |
| 4 | 그림 답변이나 위로 |
| 5 | 마무리 + "다음 사연은 댓글로" 엔딩 |

댓글 작성자 아이디는 지우거나 바꾼다.

## 14. quiz — 퀴즈·선택형 (넘겨서 정답)

표지에서 문제, 다음 장에서 정답. 정답이 하나인 소재(맞춤법, 상식, 직무 용어). (이론)

| 장 | 역할 |
| --- | --- |
| 1 | 표지: 문제 |
| 2 | 보기 2~3개 |
| 3 | "정답은 다음 장" 뜸 |
| 4 | 정답 |
| 5~6 | 해설 |
| 7 | 함정·오답 이유 |
| 8 | 엔딩 (몇 개 맞혔는지 댓글) |

## 15. sponsored — 협찬 공감 해결형 (브랜디드툰)

공감 상황에서 시작해 제품이 해결 도구로 늦게 등장한다. (업계 가이드)

| 장 | 역할 |
| --- | --- |
| 1 | 표지: 상황 제목 + **광고 표기** |
| 2 | 독자가 겪어 봤을 상황 |
| 3~5 | 문제가 커지는 과정 |
| 6 | 전환: 제품이 자연스럽게 등장 (처음 등장) |
| 7 | 달라진 장면과 웃음 |
| 8 | 작가 한 줄 후기 + 광고 표기 |

광고 티를 줄이는 장치: 제품 등장은 6장 이후, 핵심 장점 하나만, 작가 평소 말투 유지, 작은 단점이나 한계 한 컷, 웃음으로 마무리. 표기를 줄이는 것은 광고 티를 줄이는 방법이 아니다.

## 16. groupbuy — 공구·이벤트 연동형

sponsored 이야기 뒤에 혜택과 참여 방법 장을 붙인다.

| 장 | 역할 |
| --- | --- |
| 1~7 | sponsored 와 같은 이야기 |
| 8 | 혜택: 가격, 구성, 사은품 (narration 상자) |
| 9 | 방법과 기한: 기간, 구매 경로(프로필 링크), 마감, 광고 표기 |
| 10 | 엔딩: 작가 한마디 |

가격·기간·배송비·옵션 추가금은 브랜드가 준 값만 쓴다.

## 광고 표기 규칙 (sponsored, groupbuy)

공정위 「추천·보증 등에 관한 표시·광고 심사지침」(2026-06-01 시행 예규) 기준. 법률 자문이 아니다. 최신 지침을 확인한다.

- 위치: 사진 안, 캡션 첫 줄, 첫 해시태그 중 하나 이상. "더보기" 뒤, 댓글, 프로필, 링크 뒤는 안 된다.
- 사진 안에만 표기하면 **모든 장**에 넣어야 한다. 그래서 기본값은 캡션 첫 줄 "#광고" + 표지 광고 칩이다.
- 문구는 한글: 광고, 유료광고, 상업광고. 대가에 맞게 "상품 협찬"(제품만), "광고비 지급"(돈) 등. AD, PR, Sponsored, ○○×작가, 체험단은 쓰지 않는다.
- 배경과 구분되는 크기와 색으로. 게시 기간이 끝나도 지우지 않는다.
- 인스타그램 "유료광고 포함" 레이블은 따로 켠다. 레이블만으로 대신하지 않는다.
- 제품 장점 문장은 실제 경험과 맞아야 한다.
