# QA 체크리스트

toon qa 는 자동 검사와 "시각 점검 필요" 목록을 함께 낸다. 자동 검사가 통과해도 시각 점검을 건너뛰면 안 된다.

## 자동 검사가 잡는 것 (toon qa)

- 채택 이미지 존재, 세로 4:5 비율(0.75~0.85)
- letter.json 구조(box 순서, tail 형식), 존재하지 않는 대사 id
- letter.json 텍스트와 storyboard 대사의 문자열 일치(공백·"…"/"..." 차이는 무시), 빠진 대사
- 글자 넘침(최소 글자 크기에서도 박스에 안 들어감), 풍선(꼬리 포함)이 캔버스 밖으로 나감
- 풍선 박스끼리 겹침(경고)
- lettered.png 가 없거나 letter.json·원본보다 오래됨
- 승인 여부

## 자동 검사가 못 잡는 것 (직접 view_image 로 확인)

자동 검사는 그림의 내용을 보지 못한다. 아래는 전부 눈으로 본다.

1. **캐릭터 속성**: character.json 의 check_attributes(예: 단발 웨이브, 링 귀걸이, 니트 가디건, 토트백)가 그림에 있고 시트와 같은가. 얼굴 비율·머리 모양이 장마다 흔들리지 않는가.
- **시선과 화면 방향**: 인물이 휴대폰·노트북·모니터를 보는 장면에서 화면이 인물 쪽을 향하는가. 화면 내용(버튼, 사진)이 독자에게 보이는데 인물 얼굴도 정면이면 물리적으로 불가능한 구도다. 화면 내용을 보여 줘야 하면 장면 문구를 어깨 너머 시점(over-the-shoulder, 인물 뒤에서 화면과 옆얼굴이 함께 보이게)으로 쓰고, 표정을 보여 줘야 하면 화면을 독자 반대쪽으로 돌린다(screen faces away from viewer).
2. **로고·브랜드**: 옷, 노트북, 화면, 간판, 컵에 로고나 상표 모양이 없는가. 있으면 재생성.
3. **목록 밖 글자**: in_image_text 에 없는 글자(간판, 화면, 책 표지, 의미 없는 가짜 글자 포함)가 그림에 없는가. 목록에 있는 글자는 철자가 정확한가.
4. **실존 인물**: 실존 인물이나 유명인을 닮은 얼굴이 없는가.
5. **풍선이 얼굴을 가림**: lettered.png 에서 풍선·표지 제목·라벨이 얼굴, 손, 핵심 소품을 덮지 않는가. 꼬리가 말하는 인물을 가리키는가.
6. 풍선 글자 가독성(너무 작지 않은가), 표지 제목이 인물 얼굴과 겹치지 않는가.
7. 장면이 콘티와 맞는가(소품, 인원, 행동).

## 판정 기록

각 장마다 "자동 통과 / 시각 점검 완료(무엇을 보았는지) / 수정함"을 사용자에게 보고한다. 보지 않은 항목은 "미확인"으로 쓴다.
